# OneCheck 발표자료

> AI 기반 퇴직연금 명부 검증 플랫폼

---

# 1. 서론 — 왜 만들었는가

---

## 1-1. 현재의 문제점

### 지금 우리의 업무 프로세스

```
[고객사]                              [우리 회사]
   │                                      │
   │  ① 엑셀 명부 메일로 전송               │
   │  ──────────────────────────────→     │
   │                                      │  ② 수동으로 매크로 실행 (2~3시간)
   │                                      │  ③ 오류 목록 수작업 정리 (1시간)
   │                                      │
   │     ④ "이 부분 수정해주세요" 메일       │
   │  ←──────────────────────────────     │
   │                                      │
   │  ⑤ 수정본 다시 메일로 전송              │
   │  ──────────────────────────────→     │
   │                                      │  ⑥ 다시 매크로 실행...
   │                                      │
   │            ♻️ 반복 2~3회...             │
```

### 이게 왜 문제인가?

| 문제 | 설명 |
|------|------|
| **시간** | 파일 1개당 3~4시간, 수정 왕복까지 하면 1~2일 |
| **보안** | 개인정보가 담긴 엑셀 파일이 **이메일로 왔다갔다** |
| **비효율** | 고객사는 결과 나올 때까지 마냥 대기 |
| **속인화** | 검증 기준이 담당자 경험에 의존 → 일관성 없음 |
| **컬럼명** | 고객사마다 "급여/기준급여/월급여/연봉" 등 다 다름 |

---

## 1-2. 우리의 해결 방향 — 3가지 핵심 키워드

```
┌────────────────────────────────────────────────────────────────────┐
│                                                                    │
│     🎯  편리성          ⚡  자동화          🔬  정확성              │
│                                                                    │
│   심플한 5단계 흐름      검증/매핑/학습      AI + 규칙 하이브리드     │
│   엑셀 느낌 편집기       전부 자동           매크로 21개 100% 커버   │
│   3색 요약으로          텔레그램 알림까지     + 학습으로 계속 향상    │
│   결과 1초 파악          사람 개입 최소화     미지의 오류도 탐지      │
│                                                                    │
└────────────────────────────────────────────────────────────────────┘
```

### 지금 당장: 명부 검증 자동화 플랫폼

```
[고객사 파일]  →  [웹 플랫폼에서 자동 검증]  →  [즉시 결과 확인]  →  [텔레그램 알림]
                     5분 이내                    수정도 웹에서          실시간 통보
```

- **편리성**: 메일 주고받기 없이 웹에서 바로 검증, 결과도 바로 확인
- **자동화**: 컬럼 매핑 → 3단계 검증 → 리포트 생성 → 알림까지 전부 자동
- **정확성**: 기존 매크로 에러체크 100% + AI가 맥락적 판단 + 쓸수록 학습

### 앞으로의 비전: 원패스 시스템

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  명부 검증    │ →  │  재정 검증    │ →  │  퇴직급여     │
│  (현재 완성)  │    │  (확장 예정)  │    │  계산까지     │
└─────────────┘    └─────────────┘    └─────────────┘
         ↑
      지금 여기
```

> **목표**: 명부 받으면 → 검증 → 재정검증 → 퇴직급여 산출까지 **원패스**로 끝내는 시스템

# 2. UI Flow — 편리성 + 자동화

> 심플한 흐름 + 깔끔한 UI + 사람이 할 일은 최소화

---

## 2-1. 전체 흐름 (5단계)

```
┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐
│ 로그인    │ → │ 진단 질문  │ → │ 파일 업로드│ → │ 검증 결과 │ → │ 다운로드  │
│ + 모드선택 │   │ (7페이지) │   │ + AI매핑  │   │ + 수정   │   │ + 알림   │
└──────────┘   └──────────┘   └──────────┘   └──────────┘   └──────────┘
```

**사용자가 하는 일**: 로그인 → 질문 답변 → 파일 올리기 → 결과 확인 → 끝
**나머지는 전부 자동**: 컬럼 매핑, 3단계 검증, 리포트 생성, 텔레그램 알림

---

## 2-2. Step 0: 로그인 — 1초 만에 시작

```
┌──────────────────────────────────────────────────┐
│                                                  │
│               OneCheck                            │
│        퇴직연금 명부 검증 시스템                    │
│                                                  │
│   ┌────────────────────────────────────────────┐ │
│   │  아이디    [admin@company.com           ]  │ │
│   │  비밀번호  [••••••••                    ]  │ │
│   │                                            │ │
│   │  검증 모드                                  │ │
│   │  ┌──────────────┐  ┌──────────────┐       │ │
│   │  │ ○ Basic      │  │ ● Complete   │       │ │
│   │  │   빠른 확인   │  │   정밀 검증   │       │ │
│   │  └──────────────┘  └──────────────┘       │ │
│   │                                            │ │
│   │              [ 로그인 ]                     │ │
│   └────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────┘
```

**UI 편의성 포인트:**
- 모드 선택이 **로그인 화면에 바로** 있음 → 별도 설정 페이지 불필요
- Basic(빠른 확인)과 Complete(정밀 검증) 중 **원클릭 선택**

---

## 2-3. Step 1: 진단 질문 — 위자드 형태로 간편 입력

```
┌──────────────────────────────────────────────────┐
│  진단 질문 - 2/7 페이지                            │
│  ▓▓▓▓▓▓▓▓▓░░░░░░░░░░░  28%                      │
│                                                  │
│  [평가대상/퇴직급여]                               │
│                                                  │
│  2-0. 작성기준일: [ 2025-12-31  ]                 │
│                                                  │
│  2-a. 재직자 수                                    │
│       임원:   [   8  ] 명                         │
│       직원:   [ 110  ] 명                         │
│       계약직: [   0  ] 명                         │
│       ──────────────                             │
│       합계:     118명 (자동계산)                   │
│                                                  │
│          [ ← 이전 ]           [ 다음 → ]          │
└──────────────────────────────────────────────────┘
```

**UI 편의성 포인트:**
- **7페이지 위자드** → 한 화면에 모든 질문을 쏟아내지 않음 (단계별로 깔끔)
- **진행률 바** → 지금 어디까지 왔는지 한눈에
- **자동 합계 계산** → 임원+직원+계약직 입력하면 합계 자동 표시
- **이전/다음 네비게이션** → 언제든 돌아가서 수정 가능

---

## 2-4. Step 2: 파일 업로드 → AI가 자동 매핑

```
┌──────────────────────────────────────────────────┐
│  헤더 매핑 결과              ✅ 자동 매핑 8/10     │
│  ───────────────────────────────────────────────  │
│                                                  │
│  고객 컬럼명            →   표준 컬럼     신뢰도   │
│  ─────────────────────────────────────────────── │
│  사번                  →   사원번호      95% ✓   │
│  기준급여(원)          →   기준급여      92% ✓   │
│  입사년월일            →   입사일자      90% ✓   │
│  생년월일              →   생년월일      98% ✓   │
│  퇴직금추계액          →   당년도퇴직금   88% ✓   │
│  직종코드              →   종업원구분    85% ✓   │
│  ⚠️ 비고               →   [드롭다운 선택▼]  수동 │
│                                                  │
│                   [ 검증 시작 ]                    │
└──────────────────────────────────────────────────┘
```

**UI 편의성 포인트:**
- 파일 올리면 **AI가 알아서 컬럼 매핑** → 사용자는 확인만
- 매핑 안 된 컬럼은 **드롭다운으로 수동 선택** 가능
- **신뢰도 %** 표시 → 매핑 품질을 투명하게 확인

---

## 2-5. Step 3: 검증 결과 — 한눈에 파악

### 결과 요약 (3색 신호등)
```
┌──────────────────────────────────────────────────┐
│  검증 결과        신뢰도: 87.5%                    │
│  ───────────────────────────────────────────────  │
│                                                  │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐       │
│  │  🔴  93  │  │  🟡  13  │  │  🟢 644  │       │
│  │  오류    │  │  경고    │  │  정상    │       │
│  └──────────┘  └──────────┘  └──────────┘       │
│                                                  │
│  [ ▼ 오류 목록 (93건) ]                           │
│  [ ▼ 경고 목록 (13건) ]                           │
│  [ ▼ 컬럼 매핑 상세 ]                             │
└──────────────────────────────────────────────────┘
```

**UI 편의성 포인트:**
- **3색 요약** → 빨강/노랑/초록으로 전체 상황 1초 만에 파악
- **접이식 목록** → 필요한 부분만 펼쳐서 확인 (화면 깔끔)
- 신뢰도 % → 숫자 하나로 검증 품질 확인

### 오류 상세 — 값 수정 / 값 유지 (핵심 UX)
```
┌──────────────────────────────────────────────────┐
│  🔴 행 80 | 사원번호: 190001                       │
│  필드: 차년도퇴직금추계액                            │
│  오류: 필수 값 누락 (임원/계약직/정년초과자)           │
│                                                  │
│     [ 🔧 값 수정 ]     [ ✅ 값 유지 ]              │
│                         (이건 오류 아님 → 학습)     │
│                                                  │
│  🔴 행 81 | 사원번호: 190002                       │
│  ...                                             │
│                                                  │
│  ┌────────────────────────────────────────────┐  │
│  │  💡 전체수정: 스프레드시트 편집기에서 일괄 수정  │  │
│  │     [ 전체수정 (93건) ]                      │  │
│  └────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────┘
```

**UI 편의성 포인트:**
- 오류마다 **2가지 선택**: 값 수정 (수정할래) / 값 유지 (이건 오류 아님)
- "값 유지" 클릭하면 **AI가 학습** → 다음에 같은 건 안 잡음
- **전체수정** 버튼 → 스프레드시트 편집기에서 한꺼번에 수정

### 스프레드시트 편집기 — 엑셀처럼 바로 수정
```
┌──────────────────────────────────────────────────┐
│  명부 편집기                    Undo / Redo       │
│  ───────────────────────────────────────────────  │
│  │사원번호│생년월일  │입사일자  │기준급여  │퇴직금│ │
│  ├───────┼────────┼────────┼────────┼─────┤ │
│  │190001 │19600616│20070701│9,170,000│ ←🔴│ │
│  │190002 │19610315│20120701│6,311,827│ ←🔴│ │
│  │190003 │19851026│20150201│4,474,741│     │ │
│  │...    │        │        │        │     │ │
│                                                  │
│  [ 적용 (재검증 자동 실행) ]       [ 취소 ]        │
└──────────────────────────────────────────────────┘
```

**UI 편의성 포인트:**
- **엑셀 느낌 그대로** → 별도 프로그램 없이 웹에서 바로 편집
- 오류 셀에 **빨간 표시** → 어디를 수정해야 하는지 바로 보임
- **Undo/Redo** 지원
- "적용" 클릭 → **자동 재검증** → 오류 0건이면 바로 성공 처리

```
└───────────────────────────────────────────────────────────────┘
```

### 기존 vs OneCheck 워크플로우

```
기존: 고객사 파일 받음 → 매크로 실행 (2~3시간) → 메일 발송 → 고객사 메일 확인 (?)
                                                               ↑ 언제 볼지 모름

신규: 파일 업로드 → 자동 검증 (5분) → 텔레그램 알림 → 클릭 → 즉시 확인
                                      ↑ 바로 알림옴          ↑ 1초
```

> 고객사 대기 시간: **3~4시간 → 5분**

|---|------|

# 3. 로직 & 차별화 — 자동화 + 정확성

---

## 3-1. 3단계 검증 엔진 (L1 + L2 + AI)

```
┌─────────────────────────────────────────────────────────┐
│  Layer 1: 형식 검증 (하드코딩 룰 21개)           0.1초   │
│  ─────────────────────────────────────────────────────  │
│  필수값, 날짜 형식, 금액 범위, 음수, 연령 체크 등          │
│  → 확실한 오류를 빠르게 잡음 (기존 매크로 21개 룰 100%)   │
└─────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────┐
│  Layer 2: 교차 검증 (진단 질문 vs 명부)            0.5초   │
│  ─────────────────────────────────────────────────────  │
│  재직자수 일치?, 급여총액 일치?, 중복 사원번호?            │
│  → 진단 질문 답변과 실제 데이터 자동 비교                  │
└─────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────┐
│  Layer 3: AI 검증 (GPT-4o)                       3~5초   │
│  ─────────────────────────────────────────────────────  │
│  정년초과 탐지, 패턴 이상, 맥락적 오류 추론               │
│  + 학습된 패턴 반영 (사용자 피드백 기반)                   │
│  → L1이 못 잡는 복합적 판단                              │
└─────────────────────────────────────────────────────────┘
```

## 3-3. AI가 만드는 차이 — 매크로를 넘어서

```
┌─────────────────────────────────────────────────────────────┐
│  기존 매크로 21개 룰  ──────→  L1 하드코딩으로 100% 커버     │
│                                                             │
│  + AI (Layer 3)가 추가로 하는 것:                             │
│                                                             │
│  ① 맥락적 판단                                               │
│     "임원인데 급여가 일반직원보다 낮다" → 매크로로는 불가능     │
│     "정년 60세인데 65세 재직자가 있다" → 진단 질문 기반 추론    │
│                                                             │
│  ② 학습 → 다음에 더 정확하게                                  │
│     사용자가 "이건 오류 아님" 클릭 → L1, AI 모두 학습         │
│     같은 패턴 다음에 다시 안 잡음 (false positive 감소)       │
│                                                             │
│  ③ 지금까지 발견 못한 오류도 탐지                              │
│     하드코딩 룰에 없는 이상 패턴도 AI가 추론                   │
│     예: "입사 1년 미만인데 퇴직금추계액이 비정상적으로 높음"    │
│                                                             │
│  이 모든 검증은 개인정보(주민번호/이름/전화번호) 없이 수행      │
│  → 개인정보 침해 없이 검증 100% 가능                          │
└─────────────────────────────────────────────────────────────┘
```

## 3-4. 자율 학습 — 쓸수록 정확해진다

### 학습 파이프라인

```
[사용자 "값 유지" 클릭]
         │
         ▼
  ┌──────────────┐      ┌──────────────────┐
  │ dismiss-error │ ──→  │ learned_patterns  │  (SQLite DB)
  │ API 호출      │      │ 테이블에 저장      │
  └──────────────┘      └────────┬─────────┘
                                 │
              ┌──────────────────┼──────────────────┐
              ▼                  ▼                  ▼
    ┌──────────────┐  ┌──────────────────┐  ┌─────────────┐
    │ L1 검증      │  │  AI(L3) 검증     │  │ behavior    │
    │ 에러 직접    │  │  프롬프트에       │  │ events 축적 │
    │ 억제         │  │  "오류 아님" 지시 │  │ (자동 분석) │
    └──────────────┘  └──────────────────┘  └─────────────┘
```

### 실제 결과

```

           사용자가 93건에 "값 유지" 클릭

[학습 후]  같은 파일 다시 검증 → 오류 4건 (93건 자동 억제)
           → "학습 패턴 적용됨" 투명하게 표시
```

## 3-5. 다른 팀과의 차별화 — 왜 우리가 다른가

| 구분 | 다른 팀 (일반 접근) | OneCheck |
|------|:----------------:|:------------:|
| 검증 방식 | AI만 or 규칙만 | **AI + 규칙 하이브리드** (비용 최적화) |
| 매크로 호환 | 새로 만듬 | **기존 21개 룰 100% 호환** (업무 연속성) |
| AI 없을 때 | 작동 안 함 | **100% 동작** (Graceful Degradation) |
| 학습 | 수동 설정 | **자동** (클릭만 하면 학습) |
| 교차 검증 | 형식만 체크 | **진단 질문 답변 vs 명부 자동 비교** |
| 개인정보 | 이름/주민번호 포함 | **설계 단계에서 PII 배제** |
| UI | 기능 중심 | **고객 편의성 중심** (엑셀 편집기, 3색 요약) |
| 알림 | 없음 / 이메일 | **텔레그램 실시간** |

## 3-6. 개인정보 보호 — 설계 단계부터 안전

### 핵심: "마스킹이 필요 없게 설계한 것 자체가 보안"

```
퇴직금 검증에 필요한 데이터        개인 식별 정보 (PII)
─────────────────────────        ──────────────────────
✅ 사원번호 (내부 코드)            ❌ 주민등록번호 — 불필요
✅ 생년월일 (연령 계산용)          ❌ 이름 — 선택 (없어도 검증 가능)
✅ 입사일자                       ❌ 전화번호 — 불필요
✅ 기준급여                       ❌ 이메일 — 불필요
✅ 퇴직금추계액                   ❌ 주소 — 불필요
```

> 메일로 주고받던 엑셀에는 이름, 주민번호가 들어있었음
> OneCheck는 **그런 정보 없이도** 검증이 가능하게 설계
> 만약 고객이 포함해서 보내더라도 → **PII 자동 탐지 & 마스킹 모듈**이 대비

## 4-1. 수작업 vs OneCheck 비교

| 항목 | 기존 (메일 + 매크로) | OneCheck |
|------|:------------------:|:------------:|
| 검증 시간 | 2~3시간 | **5분 이내** |
| 결과 전달 | 메일 (언제 볼지 모름) | **텔레그램 즉시 알림** |
| 컬럼 매핑 | 수동 확인 | **AI 자동 매핑** |
| 에러체크 | 매크로 21개 | **21개 + AI 추가 5개** |
| 수정 | 엑셀 열고 수동 | **웹에서 바로 편집 + 재검증** |
| 학습 | 불가 | **자동 학습 (쓸수록 향상)** |
| 보안 | 엑셀 파일 메일 왕복 | **웹 플랫폼 + PII 불필요 설계** |
| 이력 관리 | 없음 | **대시보드 + 감사 로그** |

## 4-2. 핵심 강점 — 편리성 / 자동화 / 정확성

```
🎯 편리성
   → 심플한 5단계 흐름, 엑셀 느낌 편집기, 3색 요약, 원클릭 수정
   → 고객이 헤매지 않는 깔끔한 UI
   → 대시보드로 전체 현황 한눈에 (상사 보고용으로도 완벽)

⚡ 자동화
   → 컬럼 매핑 → 3단계 검증 → 리포트 → 텔레그램 알림 전부 자동
   → 매크로 21개 에러체크 완전 대체 (업무 변경 없이 전환)
   → 사용자 피드백도 자동 학습 (클릭만 하면 다음에 반영)
   → 고객 대기 시간 3~4시간 → 5분

🔬 정확성
   → AI + 규칙 하이브리드로 확실한 것 + 복잡한 것 모두 커버
   → 맥락적 판단 (매크로로는 불가능한 것도 AI가 잡아냄)
   → 쓸수록 학습 → false positive 감소, 정확도 자동 향상
   → 개인정보 없이 검증 → 보안과 정확성 동시 달성
```
