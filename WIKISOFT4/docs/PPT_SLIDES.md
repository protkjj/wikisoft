## 슬라이드 2: 문제

**파일 하나에 3~4시간, 왕복하면 1~2일**

```
고객사                              우리
  │  ① 엑셀 메일 전송  ──────→      │  ② 매크로 수동 실행 (2~3시간)
  │    ←──────  ③ "수정해주세요"     │
  │  ④ 수정본 재전송  ──────→       │  ⑤ 다시 매크로...
  │         🔄 2~3회 반복            │
```

**느리다 / 위험하다 / 사람에 의존한다**

---

## 슬라이드 3: 해결 — 편리성 · 자동화 · 정확성

**파일 올리면, 나머지는 전부 자동**

| 기존 | OneCheck |
|:---:|:---:|
| 3~4시간 | **5분** |
| 메일 왕복 | **웹에서 바로** |
| 매크로 수동 | **AI + 규칙 자동** |
| 학습 불가 | **쓸수록 향상** |

```
파일 업로드 → AI 매핑 → 3단계 검증 → 결과 확인 → 텔레그램 알림
 (사용자)      (자동)     (자동)      (사용자)      (자동)
```

## 슬라이드 4: UI — 로그인 + 진단 질문

(스크린샷 2장)

**로그인**: Basic/Complete 모드 원클릭 선택
**진단 질문**: 7페이지 위자드 · 진행률 바 · 자동 합계
→ 이 답변이 검증 기준이 됨 (정년 60세 입력 → 초과자 자동 탐지)

---

## 슬라이드 5: UI — AI 매핑 + 3색 결과

(스크린샷 2장)

**AI 매핑**: 고객 컬럼 → 표준 컬럼 자동 매핑 (신뢰도 % 표시)
**검증 결과**:
```
🔴 93 오류     🟡 13 경고     🟢 644 정상     신뢰도 87.5%
```

---

## 슬라이드 6: UI — 값 수정/값 유지 + 스프레드시트

(스크린샷 2장)

**오류마다 2가지 선택:**
- 🔧 값 수정 → 스프레드시트에서 엑셀처럼 바로 편집
- ✅ 값 유지 → "이건 오류 아님" → AI가 학습, 다음에 안 잡음

**스프레드시트**: 오류 셀 빨간 표시 · Undo/Redo · "적용" → 자동 재검증

## 슬라이드 8: 로직 — 3단계 검증 + 매크로 100%

**확실한 건 코드로, 복잡한 건 AI로**

```
L1 형식 검증 (0.1초)  →  21개 룰 (기존 매크로 100% 커버)
L2 교차 검증 (0.5초)  →  진단 답변 vs 명부 자동 비교
L3 AI 검증 (3~5초)    →  정년초과, 패턴 이상, 맥락 추론
```

**+ OneCheck만**: 교차검증 / AI 정년초과 / 패턴 이상 / 학습 억제 / 미래 입사일

---

## 슬라이드 9: 로직 — AI + 자율 학습

**매크로로는 불가능한 것 + 쓸수록 정확해지는 것**

| 매크로 | OneCheck |
|:---:|:---:|
| 규칙만 | **맥락적 추론** |
| 학습 불가 | **클릭 한 번으로 학습** |
| 고정 21개 | **미지의 오류도 탐지** |

```
학습 전: 오류 97건  →  학습 후: 오류 4건 (93건 자동 억제)
```

> 개인정보(주민번호/이름/전화번호) 없이 이 모든 검증 수행

---

## 슬라이드 10: 차별화 + 보안

**왜 우리가 다른가**

| | 일반 | OneCheck |
|---|:---:|:---:|
| 검증 | AI만 or 규칙만 | **하이브리드** |
| 매크로 호환 | 새로 만듦 | **21개 100%** |
| AI 없을 때 | 작동 안 함 | **100% 동작** |
| 개인정보 | 필요 | **PII 불필요 설계** |

**보안**: 검증에 주민번호·이름·전화번호 불필요 → 수집 자체를 안 함
만약 포함돼도 → PII 자동 탐지 & 마스킹 안전망

파일 하나 → 검증 → 계산 → 리포트까지 **원패스**
